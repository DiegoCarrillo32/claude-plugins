# Icons

Eighteen pixel icons on a 12×12 grid of square art pixels, 24×24 CSS px. Single ink: `ink` in Day (#1f1e1d). As images they cannot follow the theme, so in an interface use the `PixelIcon` component, which fills with `currentColor`; use these files where only an image works (docs, favicons, slides on a light ground).

check, close, plus, minus, arrow-right, arrow-left, arrow-up, arrow-down, play, pause, clock, search, info, alert, star, heart, wave, shell.
