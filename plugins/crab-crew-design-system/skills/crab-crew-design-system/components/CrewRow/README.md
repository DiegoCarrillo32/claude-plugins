# CrewRow

A compact roll-call row: a still crab, its name, a status word and one facts line.

**Use it** for planned crabs (asleep, no status word), finished crabs (done pose, "done" in success) and stopped crabs (failed pose, "stopped" in danger).

**You provide** `status` (`planned`, `done`, `failed`), `look`, `description` and `facts`. Show the newest finished crabs first and cap the list at 30.
