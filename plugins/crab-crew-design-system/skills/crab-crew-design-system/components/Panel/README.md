# Panel

A sand-raised surface in a 2px frame with notched corners.

**Use it** to group a header, a form, or a set of rows. Tone `clawd` frames the one panel that belongs to Claude's own flow; `edge` frames a panel in any crab's colour. Everything else stays `plain`.

**You provide** `children`, `tone` or `edge`, and `label` when the panel is a landmark. Panels do not nest.
