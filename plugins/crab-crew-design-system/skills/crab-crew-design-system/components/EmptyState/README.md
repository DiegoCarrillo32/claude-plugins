# EmptyState

A sleeping crab, a short title and one line that says what will appear here and how it gets there.

**Use it** for any list or panel with nothing in it yet. The source copy: "The beach is quiet. Each subagent shows up here as a crab of its own."

**You provide** `title`, `children` (the one line), an optional `action` (usually a secondary Button), and `look`/`pose` to change the crab.
