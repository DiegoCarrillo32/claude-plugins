# CrabPile

The crew as overlapping crab faces, first on top, each in its own look.

**Use it** where a count of crabs needs a face: inside a button (`Crew 3`), beside a total, in a collapsed list. Show up to four; say the rest in the label.

**You provide** `looks` (the same looks the full crabs use, so they match) and `scale` (1 inside a button, 2 standalone). Give it `alt` when it is the only thing that says how many.
