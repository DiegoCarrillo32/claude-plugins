# PixelIcon

Eighteen icons drawn on a 12×12 grid of square art pixels, filled with `currentColor` so they follow the text.

**You provide** `name`, `size` (24 by default; 16 inside small buttons; keep to multiples of 12 or 8 so pixels stay whole) and `label` when the icon is the only thing that carries the meaning. Without a label it is hidden from screen readers.

Names: check, close, plus, minus, arrow-right, arrow-left, arrow-up, arrow-down, play, pause, clock, search, info, alert, star, heart, wave, shell. `window.CrabCrew.icons` lists them.
